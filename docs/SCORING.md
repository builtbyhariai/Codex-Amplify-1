# Opportunity Scoring

The 0-100 score weights demand 28%, buyer value 24%, low competition 18%, durability 16%, and feasibility 14%, then subtracts explicit compliance risk. Demand evidence must record source and observation time. Unknown legal/ToS status never auto-builds. A score is prioritization evidence, not proof of revenue.

Use search terms tied to buyer intent: API, dataset, export, monitor, leads, prices, listings, jobs, tenders, permits, filings. Penalize crowded searches, fragile UI-only sources, personal-data dependence, and targets requiring evasion. Track conversion, repeat usage, retention, cost per result, and support load after staging.
